# Streaming Customer Churn Analytics - Google Cloud

## 🌍 English

This project is a **data analytics capstone** focused on predicting and analyzing **customer churn in a streaming platform** using **Google Cloud services**.  
The goal is to build a complete data pipeline, from ingestion to visualization, in order to understand customer behavior and reduce churn.

### 🔑 Key Features
- Data ingestion and processing with **Google BigQuery & Cloud Storage**  
- Customer behavior analysis using **SQL & Python**  
- Predictive modeling of churn with **Machine Learning on Vertex AI**  
- Dashboards and KPIs with **Google Data Studio / Looker Studio**  
- Focus on **data-driven decision making** for streaming platforms  

### 📂 Project Structure
- `data/` → Sample and synthetic datasets  
- `notebooks/` → Jupyter/Python notebooks for EDA and modeling  
- `sql/` → Queries for data exploration and analysis in BigQuery  
- `dashboard/` → Screenshots and setup for Looker Studio dashboards  
- `docs/` → Documentation and reports  

### 🚀 Tech Stack
- Google Cloud: BigQuery, Cloud Storage, Vertex AI, Looker Studio  
- Python (pandas, scikit-learn, matplotlib, seaborn)  
- SQL for advanced queries  
- Git & GitHub for version control

## 🇪🇸 Español

Este proyecto es un **capstone de analítica de datos** enfocado en predecir y analizar la **deserción de clientes en una plataforma de streaming** utilizando **servicios de Google Cloud**.  
El objetivo es construir un pipeline de datos completo, desde la ingesta hasta la visualización, para comprender el comportamiento del cliente y reducir la deserción.

### 🔑 Características principales
- Ingesta y procesamiento de datos con **Google BigQuery & Cloud Storage**  
- Análisis de comportamiento de clientes con **SQL & Python**  
- Modelado predictivo de churn con **Machine Learning en Vertex AI**  
- Dashboards y KPIs con **Google Data Studio / Looker Studio**  
- Enfoque en la **toma de decisiones basada en datos** para plataformas de streaming  

### 📂 Estructura del proyecto
- `data/` → Datasets de ejemplo y sintéticos  
- `notebooks/` → Notebooks Jupyter/Python para EDA y modelado  
- `sql/` → Consultas para exploración y análisis en BigQuery  
- `dashboard/` → Capturas y configuración de dashboards en Looker Studio  
- `docs/` → Documentación e informes  

### 🚀 Tecnologías utilizadas
- Google Cloud: BigQuery, Cloud Storage, Vertex AI, Looker Studio  
- Python (pandas, scikit-learn, matplotlib, seaborn)  
- SQL para consultas avanzadas  
- Git & GitHub para control de versiones
